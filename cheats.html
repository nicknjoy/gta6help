🎮 How to enter a cheat

  1. Press D-pad Up to bring up your phone.
  2. Hold L1 (PS5) / LB (Xbox) and press R1 / RB.
  3. Type the code with the D-pad. Codes are the same on both consoles.

🔓 How cheats unlock

Cheats only become usable after you finish the story, and each one also has its own requirement (a challenge or milestone). The list appears under Progress → Cheats once the story is done. Entering a code you haven't unlocked does nothing.

Before you use one: any active cheat turns off trophies/achievements and saving. Load a separate save if you're going for 100% or the platinum.

Codes marked not found yet haven't been confirmed by reliable sources. Fake lists made from GTA 5 codes are everywhere, so we only list a code once it's been checked. Arrows = D-pad directions.
